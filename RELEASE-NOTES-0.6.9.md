## English

**Test update for Railroader 0.6.3**

- Cache unsuccessful optional translator discovery. Language refreshes use exact type lookup and retry after a new assembly loads.
- Release the assembly-load subscription when Communications unloads. English fallback and late translator activation remain supported.
- Add **Build-Local.cmd** for local compilation, automated checks and install-ZIP creation using your installed game.
- Document shared local and Cloud development through GitHub branches.

This update is based on the tested 0.6.8 package for Railroader 0.6.3. The newer voice playback and microphone-window work is preserved on a separate development branch. Compare the recurring stutters with this update installed and EnusDE Translation absent. Live confirmation of the performance effect is pending.

## Deutsch

**Testupdate für Railroader 0.6.3**

- Erfolglose Erkennung des optionalen Übersetzers wird gespeichert. Die Spracherkennung sucht gezielt nach dem Typ und prüft nach dem Laden einer neuen Bibliothek erneut.
- Beim Entladen wird die Ereignisanmeldung entfernt. Englisch als Rückfall und das spätere Aktivieren des Übersetzers bleiben erhalten.
- **Build-Local.cmd** kompiliert lokal, führt automatisierte Prüfungen aus und erstellt ein Installations-ZIP mit den vorhandenen Spielreferenzen.
- Gemeinsame Arbeit zwischen lokalem Chat und Cloud-Chat über GitHub-Branches dokumentiert.

Grundlage ist das getestete 0.6.8-Paket für Railroader 0.6.3. Die neueren Änderungen an Sprachwiedergabe und Mikrofonfenster sind auf einem eigenen Entwicklungsbranch gesichert. Prüfe die wiederkehrenden Ruckler mit diesem Update bei fehlender EnusDE Translation. Der tatsächliche Leistungseffekt im Spiel ist noch zu bestätigen.
